# Python Basic — GoIT PyCore Course Assignments

## Overview

This repository contains the complete set of assignments for the GoIT Python Core course, organised for maximum clarity and portfolio presentation. Each module demonstrates practical skills in Python, including file operations, data structures, algorithms, and problem-solving with industry-relevant scenarios.

---

## Structure

- **HW_03** — Fundamentals: Functions, Conditions, Modular Programming
- **HW_04** — File Handling, Exception Management
- **HW_05** — Working with Standard Libraries, CSV/JSON Processing
- **HW_06** — Collections, Dictionaries, Lists, and Functions
- **HW_07** — Advanced Topics: Regular Expressions, Packages
- **HW_08** — Final Capstone Assignments, Integration Skills

---

## Usage

1. Navigate to any assignment folder (`HW_03` to `HW_08`)
2. Review the code and documentation
3. Use the examples as a reference for Python practice, automation, or similar backend problems
